# Fitness Tracker

აპის კოდი არის App.js-ში. პროექტი იყენებს Expo SDK 54-ს.

## GitHub Pages-ზე გამოქვეყნება

1. შექმენი საჯარო რეპოზიტორი main ბრენჩით. შექმნისას შეგიძლია მონიშნო Add a README file.
2. Settings → Pages → Build and deployment → Source-ში აირჩიე GitHub Actions.
3. გახსენი ZIP და რეპოზიტორის მთავარ დონეზე ატვირთე შიგნით არსებული ფაილები და .github საქაღალდე. შეინახე ცვლილება main ბრენჩზე.
4. გადაამოწმე, რომ რეპოზიტორში ჩანს .github/workflows/pages.yml. თუ ბრაუზერმა დამალული საქაღალდე გამოტოვა, Add file → Create new file-ით შექმენი იმავე გზაზე და ჩასვი არქივში მოცემული pages.yml-ის შიგთავსი.
5. Actions-ში გახსენი Publish fitness app. წარმატების შემდეგ საიტის მისამართს ნახავ Settings → Pages-ში. ყოველი მომდევნო ცვლილება main-ზე ავტომატურად გამოქვეყნდება.

## მუშაობის გაგრძელება

GitHub Codespaces-ში ან კომპიუტერზე გახსენი პროექტი. გამოიყენე Node.js 22 და გაუშვი:

```sh
npm install
npm run web
```

Codespaces-ში გახსენი ტერმინალში მითითებული პორტი Ports ჩანართიდან. ტელეფონზე SDK 54-თან თავსებადი Expo Go-თი გასაშვებად გამოიყენე npm start. გამოსაქვეყნებელი ვებვერსიის ლოკალურად ასაწყობად გაუშვი npm run build. შედეგი მოთავსდება dist საქაღალდეში.
